OpenJTalkはインストールしているのだが、毎回依存関係をパス解決するのがウザすぎる。そこで簡単に呼び出せるスクリプトを書きたい。以下のような機能を持っていることとする。

## 機能要件

* `ojt.sh`というスクリプトファイルで呼び出しを簡略化したい
* 所定のディレクトリにある.htsvoiceファイルの拡張子を除いた名前で使用ボイスを指定したい
	* 存在しない名前ならエラーハンドリングする
		* `指定された音声モデルが存在しません。'ojt.sh list'で使用可能な音声モデルを確認してください。: ${指定された音声モデル文字列}`）
	* デフォルト値を設定したい
		* 音声モデルが存在するルートディレクトリ
		* 音声モデルが存在するルートディレクトリの中のどれか一つをデフォルト使用用にする
* 所定の辞書を設定したい
	* デフォルトパスを設定する（`/usr/local/dic`）
	* 任意パスを引数でセットできるようにしたい
* 入力
	* 文字列
	* テキストファイル
* 出力
	* リアルタイム発話のみ（`-w /dev/stdout`+` | aplay > /dev/null 2>&1`）
	* ファイル出力のみ
		* wav形式（デフォルト）
		* mp3形式
		* ogg形式
		* flac形式
		* 複数（wav,mp3,ogg,flac）
	* リアルタイム発話＆ファイル出力
		* 発話＋複数（wav,mp3,ogg,flac）
* 声質
	* 声の高さを半音単位で変える(`-fm`)
	* 音量（`-g`）

```sh
OJT_VOICE_ROOT=/home/pi/root/sys/env/tool/openjtalk/voice/
OJT_VOICE_EXT=.htsvoice
echo '発話したいテキスト' | open_jtalk \
	-x /usr/local/dic \
	-m "${OJT_VOICE_ROOT}mei_normal${OJT_VOICE_EXT}" \
	-ow /dev/stdout \
	| aplay > /dev/null 2>&1
```

* 実装言語はbash。fffpegなどでファイル形式変換する。

この単発実行が最低要件。実際はそれを使ってバッチ処理もしたい。内部実装では単発用スクリプトとバッチ用スクリプトを分けて実装したほうが良いだろう。ファサードではそれをシームレスに使えるインタフェース設計にしたい。

### バッチ処理

位置引数にファイルパスを指定すればバッチ処理になる。内部では`ojt silent`としてファイル出力だけを実行する。但しこちらのほうが柔軟に指定できる。音声モデルを変えたりセリフを変えたり出力ファイルは自動でインクリメントしたりする`-o`のパスはインクリメントしたファイル名として、以下のように指定できることとする。同じセリフに4ファイルすべて出力することもできるし、一つだけを指定することもできる。複数指定の場合は`{}`で囲ってカンマ区切りで形式を指定する。

```
ojt -o /tmp/voices/{wav,mp3,ogg.flac} /tmp/batch.tsv
```

尚、任意引数を渡したらそれがデフォルト値になる。

```
ojt -o /tmp/voices/{wav,mp3,ogg.flac} -d ~/mydic /tmp/batch.tsv
```
```
ojt -o /tmp/voices/{wav,mp3,ogg.flac} -m mei_happy ~/mydic /tmp/batch.tsv
```

バッチ処理で渡す台本テキストファイルは以下のような形式である。TSV形式、ハードタブ区切り。

```sh
-o --output   出力先を変更する（デフォルトはカレントディレクトリ/ojt.wav）
[位置引数]
0             入力元テキストファイルパス（省略時は標準入力から読み込む）
[初期値]
音声モデル
  Root: /home/pi/root/sys/env/tool/openjtalk/voice/
  Default: mei_normal
辞書:
  Default: /usr/local/dic
```


```sh
# 発話するだけ。ファイル出力しない。
echo '発話テキスト' | ojt -m mei_happy
```
```sh
# wav形式でファイル出力したあと発話する。
echo '発話テキスト' | ojt -m mei_happy -o /tmp/0.wav
# mp3形式でファイル出力したあと発話する。
echo '発話テキスト' | ojt -m mei_happy -o /tmp/0.mp3
# wav,mp3,ogg.flac形式でファイル出力したあと発話する。（発話するのはどれか一つだけ）
echo '発話テキスト' | ojt -m mei_happy -o /tmp/0.{wav,mp3,ogg.flac}
```
```sh
# ファイル出力のみ。発話しない。
echo '発話テキスト' | ojt silent -m mei_happy -o /tmp/0.{wav,mp3,ogg.flac}
```

もしバッチ処理がしたいなら`ojt silent`までは固定とし、`-o`のパスはインクリメントしたファイル名として、以下のようにできるはず。

```
ojt batch -o /tmp/voices/{wav,mp3,ogg.flac} /tmp/batch.txt
```

```
# /tmp/batch.txt

takumi_normal	次に発話したいテキストです。1.wavなどのファイル名で出力されます。
唱地ヨエ	最後に発話したいテキストです。2.wavなどのファイル名で出力されます。
```
