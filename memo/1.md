# 音声合成エンジン統一API作成

略名|全名
----|----
Aq|AquesTalkPi
OJT|OpenJTalk
VV|VOICEVOX core AudioQuery
PP|piper-plus
PG|piper1-gpl（本家piperの正当後継者と思われる）

統一APIによる各コマンド引数を考えたい。

ttsコマンドで各エンジンを指定し統一引数で再生できるようにしたい。出力は以下のように大きく分けて3通りのパターンがある。コマンドは基本的に同期である。非同期ではない。ファイル出力は非同期にしたいが、再生だけは同期したい場合がありえる。それをどう実現させるべきか。ファイル作成非同期＆再生同期の制御はバッチ処理や長文再生などの場面で必要となる。現在は単発コマンドのみが対象だが、将来はバッチ処理用APIも考慮すべき。そこで同期制御について考えるべき。今は音声再生による同期だけ。つまり再生が完了するまで次のコマンドを実行できない状態である。それが嫌なら出力先を`stdout`でwavバイナリデータを受け取り内部で同期処理を勝手にやらせるようにする。`task &`で非同期実行させ`wait`コマンドで全バックグラウンド処理完了待機させることが可能。

```sh
tts -e aq						# スピーカ再生のみ（リアルタイムに視聴する）
tts -e aq -o speaker			# スピーカ再生のみ（リアルタイムに視聴する）
tts -e aq -o stdout				# 標準出力する（再生制御用（中断やループなど））
tts -e aq -o /tmp/0.wav			# ファイル出力のみ
tts -e aq -o /tmp/0.{wav,flac,aac}	# wav,flac,aacの3ファイルを作成する
tts -e aq -o /tmp/{wav,flac,aac}/0.{wav,flac,aac}	# 所定のディレクトリ・ファイルに出力する
tts -e aq -o {speaker,stdout,/tmp/0.{wav,flac,aac}}	# ファイル出力し再生し標準出力する
```

将来は以下のようにバッチ処理用のAPIを作る。ファイル出力と音声再生の同期制御をする。ファイル出力は順次行う。その最中に再生を行う。再生はキューに入れて再生が完了次第次を再生する。これには時間がかかる。それが完了する間にファイル出力が完了しているはず。

```sh
tts-batch -o /tmp/{inc}.{wav,flac} ./台本.tsv
```

全体の処理は以下。

```
TTS | イコライザで音源ごとに個別音質改善 | ラウドネス正規化で音量絶対指定統一 | エフェクト | 出力（スピーカ、ファイル（無圧縮(wav),可逆圧縮(flac),不可逆圧縮(aac(mp3,ogg))）、スピーカ＆ファイル）
```

1. TTSで音声合成する
2. イコライザで音源ごとに個別音質改善する（OJTは`-b`で改善可能）
3. ラウドネス正規化で音量絶対指定統一する
4. エフェクトを掛ける
5. 出力する

## エフェクト一覧

* Effect
	* Dynamics(ダイナミクス系)
		* Compressor:
			* 概要: 指定した音量（閾値）を超えた音を圧縮し、音量のばらつきを抑える
			* 用途: ボーカルの音量均一化、ドラムのアタック感の強調
		* Limitter: 
			* 概要: 音量が絶対に指定値を超えないように完全にカット（制限）する
			* 用途: 最終出力の音割れ（クリッピング）防止
		* Gate:
			* 概要: 指定した音量以下の微小な音（ノイズなど）を完全に遮断する
			* 用途: 無音時のマイクのホワイトノイズ除去
	* Frequency(周波数系)
		* EQ(equalizer(en-US)/equaliser(en-BR)):
			* 概要: 特定の周波数帯域をブースト（強調）またはカット（減衰）する
			* 用途: 低音の不要なゴソゴソ音のカット、声のこもり解消
	* Ambient(空間系)
		* Reverb:
			* 空間の壁や天井で反射を繰り返した「残響音」をシミュレートする
			* 教会の中のような響き、広いホールの残響
		* Delay:
			* 入力された音を遅らせて、山びこのように繰り返して出力する
			* やまびこ効果、SF的なエコー演出
	* Modulation(モジュレーション系)
		* Chorus(コーラス)
			* 音をわずかに遅らせ、ピッチを揺らして重ねることで厚みを出す。
			* ボーカルやギターに広がりと厚みを持たせる
		* Flanger(フランジャー)
			* 遅延時間を周期的に変化させ、ジェット機のようなうねりを作る
			* SF的な効果音、サイケデリックな楽器音
		* Phaser：シュワシュワとした回転するような効果を与えます。
		* Tremolo / Vibrato：音量や音高を細かく揺らします。
	* Time & Pitch(時間・ピッチ系)
		* Time stretching(タイムストレッチ)
			* 音高（ピッチ）を変えずに、音の再生速度（長さ）だけを変更する。
			* 映像の尺（時間）に合わせたナレーションの長さ調整
		* Pitch shifter(ピッチシフター)
			* 再生速度（長さ）を変えずに、音の高さだけを変更する
			* モンスターの声（低音化）、宇宙人の声（高音化）
		* Pitch Correction：音程のズレを補正

## OpenJTalk

```markdown
日本語のテキスト音声合成システムである Open JTalk（[公式ソース](https://ysko909.github.io/posts/generate-voice-with-openjtalk/)より）のコマンドライン引数について、初心者にもわかりやすく解説します。
------------------------------
## 📋 基本的な使い方

open_jtalk [オプション] [入力テキストファイル]

※ [infile]（入力ファイル）を省略した場合は、標準入力（stdin）からテキストを受け取ります。
------------------------------
## 🛠️ 必須・主要オプション（まず覚えるべきもの）
音声合成を行うために最低限指定する必要がある重要なオプションです。

| オプション | データの型 | 説明 |
|---|---|---|
| -x dir | ディレクトリパス | 辞書ディレクトリのパス。テキストの漢字やカタカナの読み方を解析するための辞書（MeCab用の辞書など）を指定します。 |
| -m htsvoice | ファイルパス | 音響モデル（HTSボイス）ファイル。話者の声質（男声・女声など）を決めるファイルを指定します。 |
| -ow s | 文字列（ファイル名） | 出力するWAV音声ファイル名。生成された音声がこの名前で保存されます。 |
| -ot s | 文字列（ファイル名） | トレース情報の出力ファイル名。音声合成の過程（解析結果など）をログとして保存したい場合に指定します。 |

------------------------------
## 🎛️ 音声・音質調整オプション（声の高さや速度の変更）
デフォルト値（def）から数値を調整することで、声に変化をつけられます。

| オプション | デフォルト値 | 調整できる内容 |
|---|---|---|
| -s i | auto | サンプリング周波数（Hz）。音声の細かさです。通常は自動で最適な値に設定されます。 |
| -p i | auto | フレーム周期（ポイント）。音声波形を処理する単位時間です。 |
| -a f | auto | オールパス定数。声の太さ（キャラクター）を変えられます。数値を小さくすると低い声（男性風）、大きくすると高い声（女性・子供風）になります。（範囲: 0.0 〜 1.0） |
| -b f | 0.0 | ポストフィルタ係数。音の「こもり」を減らし、明瞭にするための調整値です。（範囲: 0.0 〜 1.0） |
| -r f | 1.0 | 話速（スピード）。1.0 が標準です。1.5 にすると1.5倍速、0.8 にするとゆっくり話します。 |
| -fm f | 0.0 | 音高（ピッチ）変更。半音単位で追加します。プラスにすると全体的に声が高くなり、マイナスにすると低くなります。 |
| -u f | 0.5 | 有声/無声のしきい値。声帯の振動がある音（母音など）と、ない音（「す」の子音など）の境界線です。（範囲: 0.0 〜 1.0） |
| -jm f | 1.0 | スペクトラム（音色）のGV重み。GV（大域的変動）は声の抑揚や自然さを保つ仕組みで、その音色への影響度です。 |
| -jf f | 1.0 | F0（基本周波数・音高）のGV重み。声のメロディ（イントネーション）の強弱に影響します。数値を上げると抑揚がはっきりします。 |
| -g f | 0.0 | 音量（ボリューム）。デシベル（dB）単位で指定します。音を大きくしたい場合はプラスの数値を入れます。 |
| -z i | 0 | オーディオバッファサイズ。0 にするとバッファが無効になります。 |

------------------------------
## 💡 実行例
最もシンプルな実行コマンドの例です。

open_jtalk \
  -x /path/to/dic \
  -m /path/to/voice.htsvoice \
  -ow output.wav \
  input.txt

設定したい声のイメージ（例: 早口にしたい、女性らしい声にしたいなど）があれば、具体的な数値を提案します。何か調整したい部分はありますか？
```

```
OJT_TXT='OpenJTalkの発話テストです。'
OJT_DIC=/usr/local/dic
OJT_MODEL=/home/pi/root/sys/env/tool/openjtalk/voice/tohoku-f01-happy.htsvoice
echo "${OJT_TXT}" | open_jtalk \
 -x "${OJT_DIC}" \
 -m "${OJT_MODEL}" \
 -ow /dev/stdout \
 -b 0.25 \
 -jf 0.75 \
 | aplay
```
